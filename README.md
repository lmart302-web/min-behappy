# min-behappy (첫 번째 버전)

## 실행 방법
1. 이 폴더를 압축 해제합니다.
2. VS Code에서 `min-behappy` 폴더를 엽니다.
3. Live Server로 `index.html`을 실행합니다.

## 현재 구현
- 날짜별 일일 기록
- 우울감 강도 1~5
- 울음별 발생 시각, 지속 시간, 강도 1~5
- 울음 추가/삭제 및 횟수 자동 계산
- 기록 저장, 조회, 수정, 삭제
- 모바일 반응형 화면

## 저장 관련 중요 사항
현재는 브라우저의 `localStorage`에 저장합니다. 따라서 같은 브라우저/기기에서만 기록을 볼 수 있고, 브라우저 데이터 삭제 시 기록이 사라질 수 있습니다. 이 버전은 화면과 기록 흐름을 먼저 확인하기 위한 시작 버전입니다.

친구의 민감한 감정 정보가 포함되므로 실제 사용 전에 Firebase 인증과 Firestore 보안 규칙을 설정해 접근을 제한해야 합니다. Firebase 연결 단계에서 기존 Firebase 프로젝트를 사용할지 새 프로젝트를 만들지 정하고, 로그인 및 데이터 접근 권한을 구성합니다.
